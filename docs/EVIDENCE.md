# Evidence and limits

Sources opened 2026-11-06 (local date); these support motivation and implementation constraints, not the untested product hypothesis.

- [TruthfulQA, ACL 2022](https://arxiv.org/abs/2109.07958): 817 questions across 38 categories test reproduction of human misconceptions. Its historical results demonstrate factual unreliability, but do not measure current free models or anime knowledge.
- [FActScore, EMNLP 2023](https://arxiv.org/abs/2305.14251): evaluates individual facts against supporting sources in generated biographies. This motivates separating supported claims from fluent prose; our exact metadata score is narrower and is not FActScore.
- [AniList rate-limit documentation, official source](https://github.com/AniList/docs/blob/master/docs/guide/rate-limiting.md): documents a temporarily reduced 30 requests/minute limit and response headers. The documentation website returned 403, so the official repository was opened instead. Our cached live responses confirm a limit of 30; the builder spaces requests by at least 2.1 seconds. Public metadata queries succeeded without authentication. Page 101 failed at the documented-in-response 5,000-entry depth limit; see the protocol amendment and raw failure artifact.
- [OpenRouter limits](https://openrouter.ai/docs/api_reference/limits): free variants have request caps determined by purchased-credit tier; provider capacity can impose additional limits. The fetched text omitted the numeric cells in the free-tier table, so **current numeric daily limits are unverified here**. The documented authenticated key endpoint exposes remaining requests; the coordinator independently confirmed the supplied credential returns 401. Our two recorded inference requests independently returned the same error. This is a credential failure, not evidence of exhausted free quota.
- [OpenRouter live model catalog](https://openrouter.ai/api/v1/models): opened through the harness HTTP client; full public response and fetch time are archived in `eval/results/baseline-2026-11-06/catalog.json`. Twelve IDs ending in `:free` had zero prompt/completion prices; the first two lexically were selected before inference. A listed model does not guarantee available inference capacity.

The 18-title snapshot yields 124 questions and two missing-field exclusions. Arm C agrees with the same records on 124/124 questions, with clustered-bootstrap CI [100%, 100%]; this is a pipeline consistency check with shared source and extraction logic. No model answer, paired comparison, accuracy improvement, long-tail advantage, or independent factual validation exists yet. Full coverage and all undefined metrics are published in the [baseline report](../eval/results/baseline-2026-11-06/summary.md).
