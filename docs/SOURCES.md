# Sources and access / 6 November 2026

This extension compares structured values deterministically and presents discussion links separately. It does not grade prose with another model, infer factual truth from votes, scrape Reddit, or copy article bodies. All links below were opened; failed access is identified rather than treated as permission or availability.

## Storage and failure behavior

Migration 0003 adds bounded normalized source caches, rolling source events and cross-isolate refresh locks. Facts cache 24 h; headline/forum metadata one hour. Existing AniList cache remains 24 h, using schema key v2 for the new identifier/fields. Duplicate refreshes coalesce in-process and a D1 lease prevents simultaneous cross-isolate fetches. If another isolate is refreshing, serve stale or mark unavailable rather than wait in a retry loop. Stale data is labelled and cannot finish a verification. Unmatched exact IDs never trigger title guessing.

The shared D1 source budget defaults to 500 attempted refreshes/day across source adapters, configurable downward to zero. Existing per-client limit remains 50 requests/day and model budgets remain atomic. Source limits use atomic D1 inserts. Jikan has a three-second and Wikidata a 5.5-second abortable deadline inside the existing total 15-second request deadline; source work runs alongside a needed model draft. Retry-After opens a persisted source cooldown. No immediate retries. Cache cleanup retains stale entries for at most seven days after expiry. Article text, Reddit content and credentials are not stored. Large responses are bounded to 200 kB and title metadata remains bounded separately.

## Evidence and limits

Live recorded fixtures: worker/tests/recorded/anilist.json and wikidata.json, each with query/timestamp. Jikan tests are explicitly schema-shaped illustrative fixtures, not recorded live responses, because access failed. Tests cover agreement/disagreement, null and stale fields, ambiguous identity, wrong drafts, cache/gates/budgets/deadline and discussion routing without network access. Existing tests run with the extension disabled to preserve the original contract; new tests enable it. Deployment enables it through MULTI_SOURCE_ENABLED=true and requires migrations before traffic.

One single adaptation cannot establish source coverage. Studio renames, split cours, airing dates and genre taxonomies can disagree without either catalog being dishonest. Fixed string/set comparisons deliberately expose those differences instead of silently inventing aliases. Next-episode schedules can change and streaming availability varies by region. The preregistered evaluation does not measure this extension; see WHY.md.

## Optional future Reddit access

An owner wishing to add real thread metadata must first read the linked policy and request explicit approval for this external application. After approval, follow Reddit's current approved app-registration flow and store REDDIT_CLIENT_ID and REDDIT_CLIENT_SECRET as Worker secrets, never in browser configuration. Registration or a free API allocation is not guaranteed. This release does not consume those secrets or call the OAuth API; search links remain usable without them. Any later adapter needs separate tests, deletion/retention handling and confirmed approved limits.
